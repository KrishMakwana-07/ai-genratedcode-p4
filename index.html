Character Info

Krish

A Computer Engineering student who lives half in the terminal and half in the sketchbook — building operating systems by night, shaping interfaces by day. Krish treats code like craft and design like architecture: nothing ships unless it's both correct and beautiful.

Raised on Linux, self-taught in the gaps between lectures, Krish is currently assembling a personal canon of tools, systems, and small worlds — DAFOX OS, DriftJS, KHUNTER — each one a chapter in the same ongoing story.

DriftJS

A lightweight scroll & motion library built to give web pages the same purposeful physicality as print — momentum, inertia, and reveal, without the framework overhead.

ProblemScroll libraries were heavy or rigid.
SolutionA minimal core with a plugin API.
StackVanilla JS, GSAP-inspired easing
Timeline3 months, ongoing
Mission Complete — v1 shipped

Operating SystemCKernel

DAFOX OS

A hobby operating system built from the bootloader up — a personal proving ground for kernel design, memory management, and the discipline of building close to the metal.

ProblemUnderstanding systems means building one.
SolutionCustom bootloader + monolithic kernel.
StackC, x86 Assembly, QEMU
TimelineIn active development
In Progress — Arc 2
